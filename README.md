# Simbang Gabi Invitation

An interactive Christmas invitation: YES/NO screen, event details, a letter, and a wish.
Plain HTML, CSS and JavaScript. No install, no backend.

## Structure
```
index.html        the page (all four screens)
css/style.css     colors (top of file) and layout
js/config.js      EDIT THIS: names, date, time, church, reminders, NO messages, letter text
js/parol.js       draws the parol lantern
js/app.js         screen switching, YES/NO logic, wish form
```

## Run locally
Double-click index.html. (Or in VS Code, use the Live Server extension.)

## Edit
Open js/config.js and change the CONFIG block and the letter text. Colors: top of css/style.css.

## Publish
Push to GitHub, then Settings > Pages > Deploy from a branch > main, / (root).
