Make the New Year email keys

This page makes two keys inside your browser. Nothing is sent anywhere.

The private key opens the wishes. Put it only in GitHub's encrypted secrets and in a password manager. Never put it in the website, in a chat or in git. If you lose it, the New Year emails cannot be written.

1. Public key

Paste this into js/config.js, replacing the null in the line that starts with const EMAIL_PUBLIC_KEY =. It is safe to publish.


2. Private key (secret)

On GitHub: your repo, Settings, Secrets and variables, Actions, New repository secret. Name: EMAIL_PRIVATE_KEY. Value: this text.
